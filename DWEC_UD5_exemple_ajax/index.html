    Exemple de càrrega AJAX

    Comparem XMLHttpRequest i Fetch amb el mateix fitxer local dades.json. Les dades són fictícies; l'exemple no consulta la IP del visitant ni depén de serveis HTTP externs.

    Descarrega els exemples complets. Descomprimeix-los i, dins de càrrega_bàsica, executa:

    Bash
    1
    python3 -m http.server 8000

    Obri http://localhost:8000/fetch.html i http://localhost:8000/ajax_pur.html. Cal servir els fitxers per HTTP, no obrir-los amb file://.

    async function carregar() {
  const eixida = document.querySelector('#resultat');
  try {
    const response = await fetch('./dades.json');
    if (!response.ok) throw new Error(`HTTP ${response.status}`);
    const dades = await response.json();
    eixida.textContent = `${dades.nom}: ${dades.curs}`;
  } catch (error) {
    eixida.textContent = `Error: ${error.message}`;
  }
}
carregar();

    const eixida = document.querySelector('#resultat');
const xhr = new XMLHttpRequest();
xhr.open('GET', './dades.json');
xhr.responseType = 'json';
xhr.timeout = 10000;
xhr.onload = () => {
  if (xhr.status >= 200 && xhr.status < 300 && xhr.response) {
    eixida.textContent = `${xhr.response.nom}: ${xhr.response.curs}`;
  } else eixida.textContent = `Error HTTP o JSON incorrecte (${xhr.status})`;
};
xhr.onerror = () => { eixida.textContent = 'Error de xarxa'; };
xhr.ontimeout = () => { eixida.textContent = 'Temps d’espera excedit'; };
xhr.send();

    Els dos HTML contenen <p id="resultat">Carregant…</p> i carreguen el seu JavaScript amb type="module". dades.json conté:

    JSON
    1
    {"nom": "Alumna de prova", "curs": "DWEC"}

    Comprova l'èxit i després reanomena temporalment dades.json: has de veure un error 404. Consulta la petició en la pestanya Network. Mostrem les dades amb textContent perquè no s'interpreten com HTML.
