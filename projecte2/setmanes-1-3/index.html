    Setmanes 1–3: de les dades a components Vue

    Setmana 1. Entorn i catàleg local

    Objectiu: identificar la reactivitat i construir la primera vista sense API.

    Apunts: Primers passos, data binding i Vite.

    Pas a pas

    1. Crea el frontend segons Materials. Guarda el catàleg inicial de backend/seed.json en src/dades.js com a export const reptes = [...] (només l'array).
    2. Substitueix App.vue per l'exemple local següent. Importa'l en main.js i munta l'aplicació sense router: createApp(App).mount('#app').
    3. Mostra nom, minuts, punts i estat amb interpolació i v-for. L'atribut :key ha de ser id, no la posició.
    4. Afig un botó que active/desactive el primer repte. Observa que la vista canvia sense querySelector() ni innerHTML.
    5. Afig un computed per sumar els minuts del catàleg. Compara una propietat calculada amb una dada emmagatzemada redundant.

    <template>
  <h1>La Vall en Joc</h1>
  <p>{{ totalMinuts }} minuts en el catàleg</p>
  <button @click="reptes[0].actiu = !reptes[0].actiu">Canvia el primer</button>
  <article v-for="r in reptes" :key="r.id">
    <h2>{{ r.nom }}</h2>
    <p>{{ r.minuts }} min · {{ r.punts }} punts</p>
    <p>{{ r.actiu ? 'Actiu' : 'Inactiu' }}</p>
  </article>
</template>
<script>
import { reptes } from './dades.js';
export default {
  data: () => ({ reptes: reptes.map(r => ({ ...r })) }),
  computed: { totalMinuts() { return this.reptes.reduce((s, r) => s + r.minuts, 0); } }
};
</script>

    Comprova: hi ha huit fitxes; el total és 245 minuts; canviar l'estat canvia el text immediatament; recarregar restaura les dades locals. Cap error a la consola.

    Pista: si veus un text com {{ r.nom }}, revisa que Vue s'ha muntat dins de #app.

    Explica: quina part s'executa al navegador? Per què aquest canvi encara no persisteix? Fita s01: catàleg local i captura.

    Setmana 3. Directives, cerca i components

    Objectiu: repartir responsabilitats entre vista i component reutilitzable.

    Apunts: Directives, pas de dades, cicle de vida.

    Pas a pas

    1. Crea RepteCard.vue. La propietat repte ve del pare i no s'ha de modificar dins del fill.
    2. Durant aquesta setmana mostra un botó «Consulta» en lloc de RouterLink, i emet seleccionar amb l'id: this.$emit('seleccionar', this.repte.id). Declara emits: ['seleccionar'].
    3. El pare escolta @seleccionar="seleccionat = $event" i mostra el nom del repte triat. Busca'l amb find().
    4. Afig q i categoria a data(), inputs amb v-model i un computed de filtratge. El filtratge és local en aquesta fase.
    5. Mostra un missatge amb v-if si no hi ha coincidències. Ordena una còpia de l'array perquè sort() no altere l'original.
    6. Compara v-if i v-show: usa el primer per a contingut que no cal muntar i el segon en una prova de mostrar/amagar repetidament.

    // Afig aquestes propietats i computed a l'App local de la setmana 1.
data() {
  return { reptes: reptes.map(r => ({ ...r })), q: '', categoria: '', seleccionat: null };
},
computed: {
  filtrats() {
    return this.reptes.filter(r =>
      r.nom.toLocaleLowerCase().includes(this.q.trim().toLocaleLowerCase()) &&
      (!this.categoria || r.categoria === this.categoria)
    ).sort((a, b) => a.nom.localeCompare(b.nom));
  },
  detall() { return this.reptes.find(r => r.id === this.seleccionat); }
}

    La plantilla del pare ha d'usar filtrats en v-for, registrar el component i contindre els controls. Prova primer la fitxa amb un sol objecte i després amb el bucle. A la setmana 4 substituiràs el botó emés per un enllaç de router; tornaràs a practicar emits amb el formulari de la setmana 5.

    Comprova: «plaça» retorna una fitxa; categoria=logica retorna dues; «zzzz» mostra l'estat buit. Modificar q actualitza la vista sense botó. El fill comunica l'id i el pare decideix què mostra.

    Pregunta: per què una prop no és el lloc adequat per guardar un canvi fet pel fill? Fita s03: components, cerca local i explicació de props/emits.

    <template>
  <h1>La Vall en Joc</h1>
  <label>Cerca <input v-model="q"></label>
  <label>Categoria <select v-model="categoria">
    <option value="">Totes</option>
    <option v-for="c in categories" :key="c">{{ c }}</option>
  </select></label>
  <p v-if="!filtrats.length">No hi ha coincidències.</p>
  <RepteCard v-for="r in filtrats" :key="r.id" :repte="r"
    @seleccionar="seleccionat = $event" />
  <section v-if="detall"><h2>{{ detall.nom }}</h2>
    <p>{{ detall.minuts }} min · {{ detall.punts }} punts</p>
    <button @click="seleccionat = null">Tanca el detall</button>
  </section>
</template>
<script>
import { reptes } from './dades.js';
import RepteCard from './components/RepteCard.vue';
export default {
  components: { RepteCard },
  data: () => ({ reptes: reptes.map(r => ({ ...r })), q: '', categoria: '',
    seleccionat: null, categories: ['logica','patrimoni','fotografia','esport'] }),
  computed: {
    filtrats() {
      return this.reptes.filter(r =>
        r.nom.toLocaleLowerCase().includes(this.q.trim().toLocaleLowerCase()) &&
        (!this.categoria || r.categoria === this.categoria)
      ).sort((a,b) => a.nom.localeCompare(b.nom));
    },
    detall() { return this.reptes.find(r => r.id === this.seleccionat); }
  }
};
</script>
