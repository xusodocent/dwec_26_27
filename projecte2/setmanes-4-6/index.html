    Setmanes 4–6: AJAX, router i CRUD amb json-server

    Setmana 4. Lectura remota i navegació

    Objectiu: substituir les dades locals per peticions HTTP i separar catàleg i detall.

    Apunts: Promeses, peticions AJAX, router i pràctica de router.

    Pas a pas

    1. Inicia json-server. Configura VITE_API_URL segons Materials i retira la importació de dades.js.
    2. Crea services/session.js i services/api.js amb les solucions següents. De moment usa només list() i detail().
    3. Explica el helper: fetch retorna una resposta, response.ok informa del status, response.text() llig el cos i intentem interpretar-lo com a JSON. Els errors del complement poden ser cadenes JSON, no objectes amb missatge.
    4. Observa l'adaptador list(): construeix _sort, _order, _page, _limit, q i categoria; llig X-Total-Count i retorna l'estructura normalitzada per a les vistes.
    5. Crea CatalogView.vue, DetailView.vue, RepteCard.vue amb RouterLink i NotFoundView.vue. Primer pots demanar mida 20; a la setmana 9 completaràs els controls de paginació.
    6. Munta el router provisional de baix. Encara no importes vistes de fases futures ni incorpores guards.
    7. Mostra càrrega, error, buit i resultats com a estats diferents. El watch de l'id del detall carrega el repte correcte quan Vue reutilitza el component.
    8. En Network compara el cos natiu (array) amb result.dades en Vue. Comprova el header del total.

    Comprova: catàleg i detall remots; id desconegut mostra error; ruta desconeguda mostra pàgina no trobada; aturar json-server mostra error de connexió. Navegar de r1 a r2 canvia el detall sense recarregar un HTML nou.

    Pista: fetch resol també amb 404; has de consultar response.ok. La normalització de list() evita repartir els detalls de json-server per tots els components.

    import { session, logout } from './session.js';
const base = import.meta.env.VITE_API_URL || 'http://localhost:3000';
export async function request(path, { method = 'GET', body, signal, withMeta = false } = {}) {
  let response;
  try {
    response = await fetch(base + path, { method, signal, headers: {
      ...(body !== undefined ? { 'Content-Type': 'application/json' } : {}),
      ...(session.token ? { Authorization: `Bearer ${session.token}` } : {}),
    }, ...(body !== undefined ? { body: JSON.stringify(body) } : {}) });
  } catch (error) {
    if (error.name === 'AbortError') throw error;
    throw new Error('No es pot connectar amb l’API. Comprova json-server.');
  }
  // json-server pot respondre amb objectes, cadenes JSON o text.
  const text = await response.text();
  let data = null;
  if (text) { try { data = JSON.parse(text); } catch { data = text; } }
  if (!response.ok) {
    if (response.status === 401) logout();
    const error = new Error(typeof data === 'string' ? data : data?.missatge || `Error HTTP ${response.status}`);
    error.status = response.status;
    throw error;
  }
  return withMeta ? { data, total: Number(response.headers.get('X-Total-Count') ?? (Array.isArray(data) ? data.length : 0)) } : data;
}
export const reptesApi = {
  // Adaptem el contracte natiu de json-server al que utilitzen les vistes.
  async list({ q = '', categoria = '', ordre = 'nom', pagina = 1, mida = 4 } = {}) {
    const filters = { _sort: ordre, _order: 'asc', _page: pagina, _limit: mida };
    if (q.trim()) filters.q = q.trim();
    if (categoria) filters.categoria = categoria;
    const result = await request('/reptes?' + new URLSearchParams(filters), { withMeta: true });
    return { dades: result.data, total: result.total, pagina: Number(pagina), mida: Number(mida) };
  },
  detail: id => request('/reptes/' + encodeURIComponent(id)),
  create: body => request('/reptes', { method: 'POST', body }),
  replace: (id, body) => request('/reptes/' + encodeURIComponent(id), { method: 'PUT', body }),
  update: (id, body) => request('/reptes/' + encodeURIComponent(id), { method: 'PATCH', body }),
  remove: id => request('/reptes/' + encodeURIComponent(id), { method: 'DELETE' }),
};
// Aquesta lectura protegida valida el token amb el servidor. No hi ha /auth/me.
export async function currentUser() {
  if (!session.user) throw new Error('Cal iniciar sessió');
  const user = await request('/users/' + encodeURIComponent(session.user.id));
  const identity = { id: user.id, email: user.email, rol: user.rol };
  session.user = identity; // No conservem el hash de contrasenya retornat pel fake server.
  return identity;
}
export async function login(email, password) {
  const result = await request('/login', { method: 'POST', body: { email, password } });
  session.token = result.accessToken;
  session.user = { id: result.user.id, email: result.user.email, rol: result.user.rol };
  try { await currentUser(); } catch (error) { logout(); throw error; }
}

    <template><form @submit.prevent="enviar" novalidate>
  <label>Nom <input v-model.trim="form.nom" maxlength="80" :aria-invalid="!!errors.nom"></label><p role="alert">{{ errors.nom }}</p>

  <label>Minuts <input type="number" v-model.number="form.minuts"></label><p role="alert">{{ errors.minuts }}</p>
  <label>Punts <input type="number" v-model.number="form.punts"></label><p role="alert">{{ errors.punts }}</p>

<script>
export default {
  props: { inicial: { type: Object, required: true }, pendent: Boolean }, emits: ['guardar'],
  data() { return { form: { ...this.inicial }, errors: {}, categories: ['logica','patrimoni','fotografia','esport'] }; },
  methods: { enviar() {
    if (this.pendent) return;
    const f = this.form, e = {};
    if (f.nom.length < 3 || f.nom.length > 80) e.nom = 'Entre 3 i 80 caràcters';
    if (!this.categories.includes(f.categoria)) e.categoria = 'Tria una categoria';
    if (!Number.isInteger(f.minuts) || f.minuts < 5 || f.minuts > 180) e.minuts = 'Enter entre 5 i 180';
    if (!Number.isInteger(f.punts) || f.punts < 0 || f.punts > 1000) e.punts = 'Enter entre 0 i 1000';
    this.errors = e;
    if (!Object.keys(e).length) this.$emit('guardar', { ...f });
  } }
};
</script>

import RepteForm from '../components/RepteForm.vue';
import { reptesApi } from '../services/api.js';
export default { components: { RepteForm }, props: { id: String },
  data: () => ({ inicial: null, error: '', errorsServidor: {}, carregant: false, pendent: false, peticio: 0 }),

    async carregar() {
      const actual = ++this.peticio; this.carregant = true; this.error = ''; this.inicial = null; this.errorsServidor = {};
      try {
        const r = this.id ? await reptesApi.detail(this.id) : { nom: '', categoria: 'logica', minuts: 20, punts: 100, actiu: true };
        if (actual !== this.peticio) return;
        this.inicial = { nom: r.nom, categoria: r.categoria, minuts: r.minuts, punts: r.punts, actiu: r.actiu };
      } catch (e) { if (actual === this.peticio) this.error = e.message; }
      finally { if (actual === this.peticio) this.carregant = false; }
    },
    async guardar(body) {
      if (this.pendent) return;
      this.pendent = true; this.error = ''; this.errorsServidor = {};
      try {
        const r = this.id ? await reptesApi.replace(this.id, body) : await reptesApi.create(body);
        await this.$router.push('/reptes/' + r.id);
      } catch (e) { this.error = e.message; this.errorsServidor = e.fields || {};
        if (e.status === 401) await this.$router.push({ path: '/login', query: { redirect: this.$route.fullPath } }); }
      finally { this.pendent = false; }
    }
  }
};
</script>

    Setmana 6. PUT, PATCH i DELETE

    Objectiu: completar el CRUD des del panell.

    Pas a pas

    1. Afig { path: '/reptes/:id/editar', component: EditorView, props: true } al router.
    2. EditorView carrega les dades abans de muntar el formulari i usa PUT per enviar tots els camps editables. No modifiques l'id.
    3. Crea AdminView, importa'l i afig { path: '/gestio', component: AdminView }. Incorpora un RouterLink de gestió al menú provisional.
    4. El botó d'estat envia PATCH amb {actiu: !r.actiu}.
    5. El botó d'eliminar demana confirmació i envia DELETE. En json-server 0.17.4 la resposta és 200 amb {}; el helper no assumeix 204.
    6. Torna a carregar el panell després de cada canvi confirmat. Si queda buida l'última pàgina, retrocedeix a l'anterior.
    7. Mantín el login manual de la setmana 5. El servidor rebutja les escriptures sense token encara que les rutes de Vue no estiguen protegides fins a la setmana 8.

    Comprova: PUT conserva l'id, PATCH conserva els altres camps, cancel·lar la confirmació no envia DELETE i GET després de la baixa retorna 404.

  <button :disabled="pendent || carregant || pagina * 4 >= total" @click="pagina++; carregar()">Següent</button>
</template>
<script>
import { reptesApi } from '../services/api.js';
export default { data: () => ({ reptes: [], total: 0, pagina: 1, error: '', carregant: false, pendent: false, peticio: 0 }),
  mounted() { this.carregar(); }, beforeUnmount() { this.peticio++; }, methods: {
    async carregar() {
      const actual = ++this.peticio; this.carregant = true; this.error = '';
      try {
        let result = await reptesApi.list({ mida: 4, pagina: this.pagina });
        if (actual !== this.peticio) return;
        if (!result.dades.length && this.pagina > 1) { this.pagina--; result = await reptesApi.list({ mida: 4, pagina: this.pagina }); }
        if (actual === this.peticio) { this.reptes = result.dades; this.total = result.total; }
      } catch (e) { if (actual === this.peticio) this.error = e.message; }
      finally { if (actual === this.peticio) this.carregant = false; }
    },
    async executar(action) {
      if (this.pendent) return;
      this.pendent = true; this.error = '';
      try { await action(); await this.carregar(); }
      catch (e) { this.error = e.message; if (e.status === 401) await this.$router.push({ path: '/login', query: { redirect: '/gestio' } }); }
      finally { this.pendent = false; }
    },
    canviar(r) { this.executar(() => reptesApi.update(r.id, { actiu: !r.actiu })); },
    eliminar(r) { if (window.confirm('Vols eliminar ' + r.nom + '?')) this.executar(() => reptesApi.remove(r.id)); }
  }
};
</script>
